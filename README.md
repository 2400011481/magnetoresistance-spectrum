# 电阻随磁场波动 —— 周期结构的检验

对 Bi 系铜氧化物超导样品的变场输运数据做频谱分析，检验 `R(B)` 中是否存在周期性结构，
并对分析流程本身做显著性校验（置换检验、正负场平台对照、两种独立的谱估计方法）。

## 数据

`data/raw_data.dat`：Origin 导出的 ASCII，**GBK 编码、制表符分隔、三行表头**
（变量 `B/R` → 单位 `T/Ω` → 组标签）。14 组数据，标签形如 `17.71Hz 10Oe/s +`。

每组是一次 -8 T → +8 T 的磁场扫描，采样间隔约 2.8 s。扫场在 **-1 ～ +1 T 区间显著放慢**，
所以数据点集中在超导转变附近。`R` 从 0 Ω（超导态）跃迁到 11.4 Ω（正常态），
转变沿在 |B| ≈ 0.4 T。

## 方法

分析只用转变两侧的**平台区**（`+0.50 ～ +1.05 T` 与 `-1.05 ～ -0.50 T`），避开转变本身的陡变。

1. **解析** `src/io_origin.py`：按 GBK 解码、定位组标签、拆出 `(B, R)`。
2. **重采样** `src/signal.py`：窗口内按 B 排序去重后插值到等间距栅格，避免非均匀采样污染频率轴。
3. **去基线**：减去 8 阶多项式拟合。平台区 R(B) 平缓，低阶多项式不会吃掉 0.08 T 的振荡
   （0.54 T 窗口内约有 7 个周期）。
4. **谱估计**：Hann 窗 FFT，幅度按正弦振幅归一化；另用 **Lomb-Scargle 周期图**
   直接处理非均匀采样（不做任何插值）做独立复核。
5. **显著性**：置换检验（打乱扰动序列 2000 次，比较最大谱峰），并做正/负场平台的独立对照。

## 结果

**全部 28 个「数据集 × 平台」组合都在同一位置出现显著谱峰：**

| 量 | 值 |
|---|---|
| 谱峰频率 | 12.7 – 13.3 1/T |
| 对应周期 | **ΔB ≈ 0.075 – 0.078 T**（中位 0.0770 T） |
| 振荡幅度 | 中位 0.033 Ω（约 R 的 0.3 %） |
| 置换检验 p 值 | 全部 0.0005（检验下限） |
| 正/负场平台峰位差 | 中位 < 0.2 1/T |

峰位在不同扫场速率（2 / 5 / 10 / 15 Oe/s）、正负磁场、以及各组标称频率下**都一致**，
Lomb-Scargle 与 FFT 两种方法给出的周期一致（0.079 vs 0.077 T）。

见 `out/fig2_perturbation.png`（去基线后的振荡，肉眼可见）、
`out/fig3_spectra.png`（幅度谱）、`out/fig4_consistency.png`（两平台对照）。

## 与既有分析的三处不同

原始分析用的步骤是「选 0.41–1.0 T 区间的数据 → 差分 + 100 点二阶平滑 → 对 0.43–0.75 T
做 FFT」。复现后确认了三处会改变结论的问题：

1. **去基线窗口过窄。** 在 0.43–0.75 T 窗口上做 100 点平滑，等效高通截止约 20 1/T，
   会把 13 1/T 的真实特征直接滤掉，只剩高频噪声。改用多项式去基线后该特征才显现。
2. **报告的是频率格点，不是峰。** 原表列出的 3.13738 / 6.27475 / 9.41213 1/T
   恰好等于该窗口频率分辨率（1/0.3187 T）的 1、2、3 倍，即频率轴的格点位置；
   按频率排序输出的前几行天然落在这些位置。
3. **缺显著性检验。** 一阶差分对白噪声的增益正比于频率，所以「差分后再看谱」的噪声本底
   本身就是上升的（原始表中振幅随频率递增 0.012 → 0.033 → 0.061，正是这个形状）。
   不做零分布对照，容易把噪声起伏读成信号。

> 原始分析给出的「~0.5 T / ~0.2 T 两个周期」在本次数据中**未获支持**：
> 二者对应 2.0 和 5.0 1/T，该处幅度低于噪声底；且 0.32 T 宽的窗口在数学上
> 无法分辨 0.5 T 的周期（可分辨的最长周期 = 窗口跨度）。这两个数字来自另一批
> **直流测量**数据，不在本仓库的数据集内，尚未检验。

